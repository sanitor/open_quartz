# OpenQuartz Studio 后续计划

## 优先顺序

1. 拆出 Video Editor 仓库，梳理与 OpenQuartz 图执行、媒体运行时和 UI 共用组件的依赖边界。
2. 建立独立仓库的 GitHub CI，覆盖构建、Rust 测试、原生 UI 回归和 Windows／macOS 硬件验收。
3. 支持移动平台，先验证触控剪辑、GPU 视频预览和端上导出。

## 后续储备

- 专业素材与时间码。以少量关键素材的导入、代理剪辑和原片交付为先，候选包括 ProRes、DNxHR 与常见 MXF 组合。
- 真正的 10-bit 专业母版、OTIO 交接完整性与 AAF。
- 素材箱和元数据管理，多机位自动同步、多个机位组与分段素材。
- 键盘精剪、四点编辑、速度曲线、保音高变速和多语言字幕。
- 混音器、音频处理、自动化与总线，后续扩展环绕声。
- 跨轨镜头组、平面与透视跟踪、稳定和复杂合成。
- 工程归档、团队审阅与协作，以及 IMF／DCP 等特殊交付。
- 发布基线和额外的 8K 性能优化。
