## Migration Matrix

- `pushHistory`: now stores a UI history marker with the current Rust graph revision; graph snapshots are owned by Rust history.
- `undo`: `Project::rollback_graph` via `Graph.rollback`; Store updates only selection and UI stack markers.
- `redo`: `Project::redo_graph` via `Graph.redo`; Store updates only selection and UI stack markers.
- `onNodesChange(remove)`: `GraphCommand::RemoveNode`; Rust performs cascade edge removal.
- `onNodesChange(position/select)`: UI/layout projection only.
- `onEdgesChange(remove)`: `GraphCommand::Disconnect`; UI-only fallback only removes stale visual edges that are not in the Rust aggregate.
- `onEdgesChange(select)`: UI projection only.
- `onConnect`: `GraphCommand::Connect`; Rust validates handles, direction, type compatibility, single target connection, and cycles.
- `isConnectionValid`: `Graph.canConnect`; Rust validates a draft connect without mutating.
- `addNode(shader/input/constant/math/renderer/onnx)`: `NodeFactoryRequest` through `Graph.createNode`.
- `addInputNode`: `NodeFactoryRequest::Input`.
- `addShaderNode`: `NodeFactoryRequest::Shader`.
- `addSystemNode`: `NodeFactoryRequest::System`.
- `addOnnxNode`: `NodeFactoryRequest::Onnx`; catalog download/status side effects remain out of graph-domain migration scope.
- `addCustomOnnxNode`: `NodeFactoryRequest::CustomOnnx`.
- `loadCustomOnnxModel`: `GraphCommand::UpdateNodeData` after resource introspection; resource preparation remains out of scope.
- `addMathNode`: `NodeFactoryRequest::Math`.
- `removeNode`: `GraphCommand::RemoveNode`.
- `removeSelectedElements`: node removals use `GraphCommand::RemoveNode`, edge removals use `GraphCommand::Disconnect`, selection cleanup stays in Store.
- `updateNodeData(shaderCode)`: `GraphCommand::UpdateShaderCode`; Rust reparses WGSL and updates ports.
- `updateNodeData(non-shaderCode)`: `GraphCommand::UpdateNodeData`.
- `updateNodeInputType`: `GraphCommand::UpdateInputType`; Rust regenerates input shader and typed output port.
- `addRendererNode`: `NodeFactoryRequest::Renderer`.
- `loadGraph`: `Graph.replace` through Rust aggregate when valid; still exists for Project I/O/screen saver callers, which were not migrated in this task.
- `clearGraph`: `Graph.replace([], [])` through Rust aggregate plus UI-only reset fields.
